Technical Methodology & Architecture

01 / Satellite Layer

Fuses Sentinel-1 SAR dampening anomalies and Sentinel-2 EO imagery for robust all-weather detection.

02 / AI Segmentation

Deep neural network segmentation model isolates dark ocean features and computes geometry metrics.

03 / Validation Engine

Cross-references wind vectors (ERA5) and ocean currents (CMEMS) to rule out biogenic and low-wind look-alikes.

04 / Lagrangian Drift

Advects slick particles backwards in time using leeway factor vector mathematics to delineate origin envelope.

05 / AIS Correlation

Filters spatiotemporal vessel trajectories against release window to identify candidate targets.

06 / Probabilistic Attribution

Multi-factor scoring algorithm balances proximity, speed anomalies, draft changes, and AIS continuity.
